Concret sur l'écran d'accueil

Une icône sur votre téléphone ou votre ordinateur : Concret s'ouvre en plein écran, comme une application. Rien à télécharger dans une boutique d'applications, aucun compte à créer.

Concret est déjà sur l'écran d'accueil de cet appareil.

Envoyer ces étapes sur WhatsApp (nouvelle fenêtre)

iPhone et iPad

  1. Ouvrez concret2027.fr dans Safari. Si le lien s'est ouvert dans WhatsApp, touchez l'icône de Safari pour l'ouvrir dans Safari.
  2. En bas de l'écran, touchez le bouton Partager (un carré avec une flèche vers le haut). Si vous ne le voyez pas, touchez ⋯, puis Partager : cela dépend de l'affichage choisi pour Safari.
  3. Touchez Sur l'écran d'accueil. S'il n'apparaît pas, touchez d'abord la flèche ⌄ en bout de ligne pour voir plus d'options.
  4. Touchez Ajouter : l'icône Concret apparaît sur l'écran d'accueil.

Téléphone en anglais : « Share », « View More », « Add to Home Screen », puis « Add ».

Android

  1. Ouvrez concret2027.fr dans Chrome.
  2. Touchez ⋮ en haut à droite.
  3. Touchez Ajouter à l'écran d'accueil (ou Installer l'application), puis Installer.

Téléphone en anglais : « Add to Home screen » ou « Install app », puis « Install ». Avec un autre navigateur : cherchez « Ajouter à l'écran d'accueil » dans son menu.

Ordinateur

  1. Chrome ou Edge : cliquez sur l'icône d'installation à droite de la barre d'adresse, puis Installer. Concret s'ouvre alors dans sa propre fenêtre, depuis le menu Démarrer ou le dossier Applications.
  2. Sans icône : dans Chrome, menu ⋮ → Caster, enregistrer et partager → Installer la page en tant qu'application ; dans Edge, menu ⋯ → Applications → Installer ce site en tant qu'application.
  3. Safari sur Mac : menu Fichier, puis Ajouter au Dock.

Firefox ne permet pas d'installer un site : ajoutez Concret à vos favoris.
